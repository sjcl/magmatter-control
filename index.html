Magmatter 生産制御 — config.lua ジェネレータ

フォームに入力すると config.lua が生成されます。「クリップボードにコピー」してゲーム内エディタへ貼り付けてください（保存不要）。複数台にも対応。

コピーしました 

    

  


  

    入力のヒント / 配置要件
    
    
      
  • アドレスは OpenComputers の Analyzer で機器を右クリックすると取得できます（先頭8文字程度の部分一致でOK）。
    • 
      
  • Fluid A / B は 2 つの Output Hatch（Spatially Enlarged Fluid / Tachyon Rich Temporal Fluid）。どちらがどちらかは区別不要（順不同）。
    • 
      
  • 各 Output Hatch 用 Transposer は、その Output Hatch（sourceSide）と Input Hatch（sinkSide）の両方に隣接させてください。
    • 
      
  • dust 用 Transposer は Output Bus（busSide）と Trashcan（trashSide）の両方に隣接させてください。
    • 
      
  • Database は通常空欄でOK（component.database を自動使用）。複数台のときは各台に専用アドレスが必須です。
    • 
      
  • 複数台では inputMeInterfaceAddress と databaseAddress を台ごとに別物にしてください（共有すると fake recipe 名が衝突し起動エラーになります）。
    •
